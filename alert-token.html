PrepperApp — Alert-worker inloggen

Geeft de alert-aggregator-worker (stap C4) tijdelijk toestemming om namens jou Incident-records aan te maken in de publieke CloudKit-database van iCloud.com.stuut.PrepperApp. Nodig na het eerste instellen, en daarna ongeveer elke twee weken opnieuw — deze pagina is bewust apart van de gewone beheerpagina, want dit is een andere inlogstap met een ander token.

1 · CloudKit API-token

Het token met de naam "Alert-aggregator worker (C4) - inlogpagina" uit CloudKit Console → je container → Tokens → API Tokens. Zet bij dat token dit adres als toegestane origin:

2 · Gedeelde sleutel van de worker

De PREPPERAPP_SHARED_KEY die ook als Cloudflare-secret bij de worker staat (wrangler secret put PREPPERAPP_SHARED_KEY).

Omgeving

3 · Inloggen

Log in met dezelfde Apple ID als je ontwikkelaarsaccount. Alleen die account heeft de rol beheerder en mag Incident-records aanmaken.

Eerst een CloudKit API-token invoeren hierboven.
